https://store.steampowered.com/app/2754380/The_Roottrees_are_Dead/

テキスト重視のarmchair detective

Type Help のファイル名推測より柔軟なWeb検索風のシステムを中心に、情報を集めていく部分のUIがいい

全体的には Type Help をよりリッチにした感じで、テキストを読むことに抵抗がなければ満足できる
Type Helpの移植([The incident at Galley House](https://store.steampowered.com/app/3641000/The_Incident_at_Galley_House/))を同じチームが開発するのも納得

顔や職業のあたり明確な根拠がないものが結構あって、最後は雰囲気で埋めたら終わってしまった

問題としてはそこまでの難易度はないものの、テキスト量が多いので照らし合わせるのが大変
あれどこに書いてあったっけと思っても辿り着くまでに時間がかかる
証拠やWebを含めた全部のテキストから検索できる機能は欲しい

クリアすると追加の問題が出てきたけどもうお腹いっぱいかなという感じ
評判通りのクオリティの高さは感じられたものの、テキストの限界を感じる
